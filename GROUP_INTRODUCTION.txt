# 🤖 Artificial Intelligence Laboratory

## 👥 Group Introduction

Welcome to our **Artificial Intelligence (AI) Laboratory Project Repository!**

We are a team of five students working collaboratively to explore and implement fundamental concepts of Artificial Intelligence through practical experiments and programming.

Our goal is to develop a strong understanding of AI algorithms, search strategies, machine learning techniques, neural networks, and intelligent problem-solving methods. Through these laboratory experiments, we aim to strengthen our programming skills, logical reasoning, and ability to solve real-world computational problems.

This repository contains our implementations and documentation for seven AI laboratory experiments. Each lab includes its source code, algorithm descriptions, and relevant output screenshots to demonstrate our practical learning and understanding.

We believe in teamwork, continuous learning, and collaborative problem-solving. This project represents our combined efforts to gain practical experience in Artificial Intelligence.

## 🎯 Our Objectives

- Understand the fundamental concepts and principles of Artificial Intelligence.
- Implement AI algorithms using C and C++.
- Explore graph traversal, informed search, and local search techniques.
- Understand machine learning, logistic regression, and neural networks.
- Implement game-playing algorithms such as Minimax.
- Explore rule-based reasoning using forward and backward chaining.
- Maintain clean, organized, and well-documented code.

## 📚 About This Repository

This repository is organized into seven laboratory folders, each dedicated to a specific set of Artificial Intelligence experiments.

The experiments cover:
- **Lab 1:** Graph Traversal and Linear Regression
- **Lab 2:** Informed Search and Local Search Algorithms
- **Lab 3:** Logistic Regression Using Gradient Descent
- **Lab 4:** AI Problem Solving Using Search Algorithms
- **Lab 5:** Minimax Algorithm for Game Playing
- **Lab 6:** Single-Layer Neural Network
- **Lab 7:** Forward Chaining and Backward Chaining

Each lab folder contains the relevant source code and README documentation, along with output screenshots where applicable.

# Artificial Intelligence Laboratory

## Group Introduction

Welcome to our **Artificial Intelligence (AI) Laboratory Project Repository!**

We are a team of five students working collaboratively to explore and implement fundamental concepts of Artificial Intelligence through practical experiments and programming.

Our goal is to develop a strong understanding of AI algorithms, search strategies, machine learning techniques, neural networks, and intelligent problem-solving methods. Through these laboratory experiments, we aim to strengthen our programming skills, logical reasoning, and ability to solve real-world computational problems.

This repository contains our implementations and documentation for seven AI laboratory experiments. Each lab folder includes its source code, algorithm descriptions, and actual program output screenshots demonstrating our results.

## Objectives

- Understand the fundamental concepts and principles of Artificial Intelligence.
- Implement AI algorithms using C and C++.
- Explore graph traversal, informed search, and local search techniques.

- Implement game-playing algorithms such as Minimax.
- Explore rule-based reasoning using forward and backward chaining.
- Maintain clean, organized, and well-documented code.
